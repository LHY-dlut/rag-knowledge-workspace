# V70 本机启动

当前 V70 验收页面为 http://127.0.0.1:18738：全新 MySQL、PostgreSQL/pgvector 卷，独立 API 和两个 worker，使用 Demo 模型。http://127.0.0.1:18657 保留 V37 的百炼小样本联调页面，不能把它写成 V70 新模型验收。原 V20 观察与 V36 回归仍使用原实例。

部署独立正式实例，在源码根目录运行：

```powershell
cd 'D:\Project\RAG高级项目\release\zhixu-rag-production-v1_81'
python artifacts/deployment_v1_81/configure_local.py
powershell -NoProfile -ExecutionPolicy Bypass -File artifacts/deployment_v1_81/start_pinned.ps1 -ProjectName zhixu-rag-v81 -Port 18786 -NetworkSubnet 10.253.242.0/24 -ValidateOnly
powershell -NoProfile -ExecutionPolicy Bypass -File artifacts/deployment_v1_81/start_pinned.ps1 -ProjectName zhixu-rag-v81 -Port 18786 -NetworkSubnet 10.253.242.0/24
```

本机 Docker 默认地址池已被此前隔离验收项目占满。上例子网经过本次网络和本机路由核对；后续被占用时需要重新选择未使用的私有 /24 子网。其他机器可省略 `-NetworkSubnet`。`-EnvFile` 可指定既有私有配置的完整路径，默认读取源码根目录 `.env`，不会覆盖它。

本地配置生成使用 Python 3.12 或以上；服务运行于锁定的 Python 3.12 容器。已有凭据 CSV 可通过 `--credentials` 指定。配置脚本保留已有 `.env`，自动生成随机 JWT 和数据库密码，并读取本文件夹原有百炼凭据；不打印密钥。先用 `MODEL_PROVIDER=demo` 可不调用百炼。私有配置不进入源码包或 GitHub。

首次初始化本地账号，可暂时设置 `.env` 的 `ENABLE_REGISTRATION=true`；建立需要的账号后恢复 false 并重启 API。默认使用原锁定模型 qwen-plus / text-embedding-v4 / gte-rerank-v2、1024 维向量。直接正式实例没有本轮验收网关的 30 元跨版本金额封顶，必须按自己的费用约束设置 MODEL_DAILY_DISPATCH_LIMIT；不要把验收网关的额度保护误认为生产代码的金额预算器。

脚本使用锁定的 Python、Node、MySQL、pgvector 与 nginx 基础镜像，执行两库迁移，启动 1 API＋2 worker。18786 避免与当前验收页面冲突；数据库与上传/成果卷按 Compose 项目独立。不要复用原工程的 ProjectName 或使用 down -v。镜像构建需要 Docker Engine 与锁文件中指定依赖的访问条件。

V70 本次实际从空卷完成完整 Compose 启动、入库、引用回答、三类成果、拒答、重复迁移和应用容器重建后的成果恢复。首次启动因 Docker 内核 AIO 配额不足失败，失败卷与日志保留；确认一个旧验收项目无待执行任务后正常停用，再用另一组空卷成功。MySQL 默认 AIO 参数没有改动；没有重置 Docker 或删除数据库数据。
