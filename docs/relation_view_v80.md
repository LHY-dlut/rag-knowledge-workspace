# 唯一关系比较输入 V80

V79保留的实际请求包含正确的焦点部分，但模型仍核对了同句其他关系，并忽略已在
完整上下文写出的失效时间。这是观测到的错误；用户问题或谓词序号是否为原因仍待实测。

显式窗口模式的比较输入移除用户问题和上游类别，只保留完整真实原文、答案上下文、
引用和唯一焦点。焦点放在上下文之后，来源谓词ID通过确定且可逆的不透明别名传输。
别名不改变事实或位置，也不代表语义匹配。返回先经严格结构校验，再逐一恢复原ID，
进入原来的证据、引用、位置、角色、独立类别及五项语义否决校验。未知ID、重复或跨角色
复用、无依据的引用均继续拒绝；不自动选择证据或改写模型否决。

旧模式保持不变，标签、原文、检索、模型、grade、generate和评分未改。首次失败和新旧
逐项结果另存，真实语义效果尚需实际调用验证，不能从Mock协议测试推断。
