# 生产候选版本的验收范围

本版本从冻结的引用协议 v3 独立复制。原源码、5 题人工标签、公开数据的官方标签与 AI 语义审阅、首次答案和历史成绩保留在原目录。GitHub 发布原按用户要求延期，2026-10-07 经用户确认后执行，仓库为 origin/main；私有配置、公开评测语料与数据库卷始终不入库。

部署目标为单机 Docker、小团队自用：10 名同时在线用户，1 个 API 和 2 个 worker；每进程模型并发为 1。数据库端口只在独立验收覆盖配置中绑定 loopback；普通部署不暴露数据库。公网接入另需 HTTPS 反向代理和访问控制，不能直接将验收端口开放到公网。

## 模型预算

沿用历史总上限 2000 次 HTTP 派发及 20 元估算上限。启动本轮时已用 1636 次，剩余 364 次，不重置。拟给新质量集最多 260 次、页面/真实容量联调最多 60 次，预留 44 次；实际调用必须由共享持久账本先预留，再发送。费用沿用原冻结费率与 usage 作估算，不能称为实时价或实际账单。超限停止；不确定的已发送请求禁止自动重发；重试、失败和响应缓存复用分别记录。压力和 24 小时运行使用 Demo，不能据此声称百炼并发吞吐。
