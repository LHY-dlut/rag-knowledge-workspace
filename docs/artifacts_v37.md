# V37：证据驱动的成果生成

本版本把新增项目的图表、报告、网页交互融入知序现有工程。输入源码 RAR 保留，核心中没有复制其 SQLAlchemy、Milvus、LiteLLM 或模型输出 HTML；仍使用 FastAPI、Tortoise、MySQL、PostgreSQL/pgvector、父子分块、Vector/BM25/RRF/Rerank、显式 LangGraph、持久 SSE 和原质量评测。

在聊天的输出选择中选“引用回答 / 证据图表 / 引用报告 / 网页预览”。已有核验回答也可点击“生成图表 / 生成报告 / 生成网页”，转换过程不调用模型。任务类型由请求的 `output_type` 明确指定，成果处理位于原 check 和业务发布事务之间，不新增隐式查询改写或模型计算。

## 证据规则

- 真实模型模式重新绑定保存的 check 事实判定、实际答案片段、实际引用 ID 和逐字证据。失败、拒答、取消、空证据及旧来源不能创建新成果。Demo 只接受带引用的逐字摘录，页面明确标识。
- 事实保留原答案字符范围；证据保留原文、文档 UUID、父块 UUID、子块 UUID、文档版本及规范化映射。字符位置是**保存的证据上下文中的 Unicode 字符位置**，不是 PDF 文件字节位置。
- 数值图只接收每个已核验句子中恰好一个明确数值，该陈述须直接匹配原文，数值 token 必须出现在绑定证据中。不同字面单位分图，不换算，不相加，不计算增长率。否定、近似、范围、多个数值、改写或不支持的数字语法保守降级为证据关系图。每个单位最多显示 30 个点，完整事实仍保留在成果数据中。
- 关系图只表示“来源支持所引用的事实”，不是自动推断出的实体知识图谱。报告与网页使用相同的核验事实和引用快照，采用后端固定章节模板；不是任意 HTML/JS 编程。
- 生成文件与上传文档共享 `/app/data` 的持久卷。数据库只存 UUID 文件名、归属、运行 ID、答案哈希、内容快照与文件哈希。下载必须携带登录凭据；没有公开静态文件目录。
- HTML 文本全部转义，CSP 禁止外部资源、脚本与表单；预览 iframe 的 sandbox 为空，不开放脚本、同源和父页面访问。

## API 与恢复

`POST /api/chat/runs` 可传 `output_type=chart|report|webpage`；默认仍为 answer。成果在最终答案之前持久记录 `artifact_ready`，终态 `done.artifacts` 与运行查询、对话历史均包含成果。前端按成果 UUID 去重。

`POST /api/runs/{run_id}/artifacts` 接收 `{"type":"report"}` 等三种类型，对同一次已接受答案幂等。`GET /api/runs/{run_id}/artifacts` 列出保存的成果；`GET /api/artifacts/{id}/download` 校验归属、知识库权限和文件哈希。

来源更新或删除后，旧成果保留快照并标记失效，不能基于旧运行继续创建成果。原 worker 的文档锁、运行租约、同会话限制及取消边界继续有效；成果文件 I/O 后再次检查租约，事务回滚时不发布成果行、事件或接受历史。文件系统和双数据库不属于同一个分布式事务：发布回滚可能留下不可通过 API 访问的孤立文件，后续需补充保留期与清理机制。转换 trace 的 elapsed_ms 当前为 0 占位，不作为耗时统计；自动生成的 artifact 节点和完整 run 耗时实际测量。
