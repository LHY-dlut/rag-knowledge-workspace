# V64 逐谓词范围绑定候选

V63字段顺序诊断18项只有10项符合，6误拒及2协议失败。全句分类集合不能标识类别属于哪个关系；两个谓词交换预测/事实性质仍可能拥有相同集合。该粒度问题不能靠集合排序或去重修复。

真实Provider新增两项严格任务：先仅读实际答案摘录各谓词的连续原文、语气及归属；后端验证摘录位置、唯一ID及所有自然文字覆盖；再按每个谓词分别读取实际引用原文中的对应关系，并填写原五项严格范围判断。第二项不收到第一次的类别或理由。后端以同一个predicate_id配对，任何未知、改变、语气或归属不一致均不能保留支持。

源码、原文、引用和答案不改写。实际引用的所有来源必须被核验；其他来源、不存在的片段、遗漏谓词和遗漏文字均协议失败。不能仅因语气类别相同认为事实支持；原基础逐事实核验、逐字绑定及五项范围判断都必须通过。原否定/条件/主体/时间边界继续有效。

原协议保留供既有显式Mock测试，真实Provider使用新协议。旧测试不删除或弱化，新回归补充集合相等但关系交换、位置与覆盖、来源、五项否定、未知及非法返回。两次任务仍是同一模型的不同读取，不是两名独立人工，也不能保证语义永远正确。模型预算、失败/重试限制、检索、grade、generate、标签与评分不变；新增输出体积可能造成预算内协议失败，须实际记录。
