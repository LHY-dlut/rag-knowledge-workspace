# grade 原文片段选择协议 v1.5

本版本只改善证据摘录的传输方式。主体、属性、适用条件、限定范围的语义判断、生成和 check 的事实标准、重试上限均保留。原 v1.4、历史答案和评分不覆盖。

后端将当前检索来源分成连续原文片段，提供 source_id、span_id、quote 与 source_start/source_end。位置为来源文本中的 Unicode 字符偏移，右端不包含；不是原始 PDF 字节偏移。换行和中文句末标点用于展示切分，超过 400 字符的单句连续切分；非空白字符全部保留，原文不修改。文档和父块映射沿用来源元数据。

grade 可在 evidence 中选择真实 source_id 与 span_id，省略 quote。同一来源的多个不相邻事实必须用多个条目，不能拼接成一条“逐字摘录”。后端重新从当前真实来源建立登记表，核对 ID 后解析原文及位置；不信任模型或客户端附带的登记表，不添加原文不存在的内容。若同时返回 quote，必须与所选整个片段一致；只允许原有可逆空白规范化，不接受标点改写、事实改写或部分匹配替代整个片段。

原来的连续 quote 方式仍可使用，也可跨展示片段或实际子块边界，但必须完整出现在同一个真实父块来源中。不能跨来源拼接，也不能自动拆分和修正模型给出的拼接摘录。重复片段有明确位置及逐条审计，不按语义相似度寻找替代引用。

ID 绑定成功只证明原文位置存在。supported_limitation 继续执行独立主体、属性与范围检查；所有最终答案继续执行引用格式检查和独立事实 check。有效片段不得使资料外问题、主体混淆、遗漏条件或扩大否定结论通过。失败继续沿用最多额外 3 次 grade、2 次 check 重试及拒答。

为避免重复传输，百炼 grade 输入的来源使用完整片段表表示原文，不再同时复制 content；其他节点继续使用完整原文。输入字节与模型预算限制不提高。片段表不是新的检索、分块或索引，实际文档、子块、索引和检索参数保持原样。

v1.6 增加字节预算回退：短句过多导致片段表请求超限时，恢复全部来源的完整 content，去掉片段表，要求模型沿用连续 quote；不截断、重写或摘要原文。实际发送负载标记 continuous_quote_budget_fallback。恢复后仍超限则沿用原上限拒绝发送，不能为绕过上限丢弃必要证据。正常片段请求与 v1.5 完全相同。
