# V75：事实证据与范围上下文

本版本在独立版本中修复核验协议，不修改标签、原文、检索、grade、generate、模型或评分规则。

`source_predicate_ids` 必须非空，只选直接支持当前主体、谓词、对象的真实原文谓词。新增 `context_source_predicate_ids` 保存标题、出处、时间、废止或归属等必要上下文的位置；默认空列表兼容旧响应。两类 ID 必须已注册、互不重复。`evidence` 必须恰好对应两类 ID 的原文位置并集。上下文不能单独支持事实，也不能改变事实证据的独立语气类别。

后端仍逐项执行主体谓词、语气、时间、条件、归属五项合取和答案／事实证据类别严格匹配。任何 changed、undetermined、未知 ID、缺失位置或混合事实类别仍拒绝。原文和答案不被重写或拼接。新增分工属于协议修复，不代表语义正确性已获证明，须单独保留真实模型复验结果。

投影提示将纯限定与被修饰关系绑定并保持字符覆盖；独立状态、日期或废止事件仍须独立核验。核验区分文书来源日期、事件时间、生效与失效时间；历史限制可在未修改答案上下文中表达，不要求某个固定短语。
