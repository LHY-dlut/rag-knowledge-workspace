# 独立原文窗口投影（实验配置）

`CHECK_SOURCE_WINDOW_PROJECTION=true` 显式启用。默认 false 保持原逐句协议，
新验收候选的配置必须记录并冻结。本变更仅用于 check，不改变检索、标签或评分。

读取至多 800 个原文字符、8 个既有证据片段的连续窗口。
预测及解释其性质的相邻句可以投影为同一个带限定的关系；独立事实必须分别投影。
模型只选后端已有 fragment ID，所有实质片段必须被覆盖；不制造合并引文。
跨句关系分别记录每个真实 span ID、原文和字符位置，再由后端绑定引用。
独立来源分类不会读取问题或系统答案，也不为配合答案改写类别。

事实和限定证据仍分角色绑定，事实证据非空；主体、语气、时间、条件、归属五项
均须 preserved。只从事实证据读取独立类别，与答案类别精确匹配；混合或待定拒绝。
引用来源并集、逐字位置、旧显式引用解析、重试限制、权限及迟到发布限制继续有效。
窗口是阅读协议，不代表自动证明事实，也不允许把不相干主体或独立事件合并。

只能用调参集和合成用例开发；新未见集不得用于修正本协议。
候选需经过真实模型边界、长答案、实际 Agent、回归、未见集和工程验收才可晋升。
