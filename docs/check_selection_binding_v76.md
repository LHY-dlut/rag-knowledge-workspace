# V76：证据ID绑定协议

模型选择支持当前唯一谓词的事实ID、必要上下文ID并返回原五项关系。后端从已核验注册表读取真实文档、句段ID和字符位置；逐部分验证其fragment ID、原文文本及偏移，再交给原引用位置／类别／五项合取核验。模型不再重复填写同一位置表。这个步骤不创造引用、不决定事实获支持，也不改变原文或答案。

旧响应若含显式evidence，仍按旧严格协议校验。缺失或无效的显式位置不会被补正；未知ID、引用外来源、注册表重复、原文漂移、角色重叠、空事实证据、错误当前谓词、类别混合或任何否决仍拒绝。reason上限、投影类别、独立来源分类、模型、预算和重试限制均保留。

提示区分当前唯一谓词与答案上下文的其他关系，避免把后者误选为当前事实证据。输出字段契约放在提示末尾，强调现有合法值，不重写非法模型返回。所有历史失败保留，真实模型效果另行记录，未验证前不作为生产通过证据。
