# V53 逐片段范围核验

V52 的开发24题通过，但两条冻结真实长答案仍错误通过，且返回的布尔值与同一回复中的理由相矛盾。原结果保留，V52不部署。

仅改变范围核验协议：按已有真实答案片段分别核对，完整原答案及实际引用来源的完整原文保留；返回五项 preserved/changed/undetermined 分类，由后端将 preserved 转为 true，另外两类转为 false。引用ID、出处、位置、覆盖及旧事实核验仍先通过，新增核验只能收紧。

文字对照以原字符位置列出 equal/insert/delete/replace，不截断或修改证据，不计算语义相似度，也不自动推断事实支持。语义判断仍逐主体、谓词、对象和限定条件进行。

增加的真实模型请求与答案片段数有关，预算、超时和已有最多额外2次生成重试仍约束它们。模型失败不伪装拒答或成功。grade、generate、检索、人工标签与评分协议均保持原样。
