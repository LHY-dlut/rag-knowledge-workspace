# V39候选：直接证据的分项组织

候选仅澄清grade提示词：概述、比较、分别说明可以把已有直接事实按子问组织。每个必要子问均须有依据，不要求原文预先写成完整答案、比较表或未问机制细节。

各自事实不证明联合行动、因果、共享机制、实际已采用或确定未来。观点与可能方式保留归属、时点和模态。明确未规定的资料范围限制、资料外拒答、主体与属性绑定保持原规则。

RRF/rerank、父子块、generate/check、引用解析、逐字证据绑定、条件校验、权限、SSE、重试上限、取消/租约栅栏以及冻结评分事实/完整性函数均未修改。

开发使用独立合成语料与冻结预期，保留旧版/新版真实判断和错误；旧公开验收题现为回归集，不能当未见集。V38仍为当前冻结演示版本；本候选验证完成前不替换其容器或发布通过结论。
