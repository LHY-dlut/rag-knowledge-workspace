# V65 服务器答案片段范围协议

V64真实诊断中的4项协议失败均已离线复现：3项遗漏答案文字/范围导语，1项模型摘录不在实际答案中。V65仅改变独立谓词摘录协议，不修改语气分类定义、五项语义关系、grade/generate、检索、标签和评分。

服务器按逗号、冒号及顿号给当前真实答案片段建立原文索引，保留所有文字、标点、空白和原始Unicode码点偏移。索引只用于选择位置，不宣称标点分段就是独立事实。模型为每个实际谓词显式选择现有连续片段ID，后端按原文直接绑定；不接受手写quote、未知ID、重复、重排、跳块拼接或遗漏必要文字。多个谓词可以显式选择重叠范围来保留共同主体/范围导语，未选导语不会自动补齐或假定生效。

片段位置正确不等于事实获支持：基础逐事实核验、实际引用来源覆盖、逐谓词原文关系及五项严格语义边界均须通过。第二项核验仍不收到独立读取的语气、归属或理由，未知分类及已有否定不能升级。原文与答案不改写，分类争议留待独立诊断。

原V64 quote协议保留给既有显式Mock回归，真实DashScopeProvider使用新严格范围协议。新增回归直接覆盖该分支。两个读取任务仍由同一模型完成，不是两名独立人工。所有历史版本、首轮结果及原5题人工标签保留。本版在原生检查与小批真实模型通过前不部署。
