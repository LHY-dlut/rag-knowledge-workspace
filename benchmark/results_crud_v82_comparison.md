# CRUD-RAG 修复前后配对对比（v1.82 片段覆盖定向重问）

对比对象：2026-10-05 修复前基线（`results_crud_20261005.json`）与 2026-10-06/07 v1.82 复测
（`results_crud_20261006_v82_dense.json`、`results_crud_20261007_v82_hybrid_full.json`）。

## 方法：为什么必须配对比较

两次评测使用同一份人工确认文件（SHA256 `d31ebec984b8186766744f315a1e1a9d23f2b231a6749c89a0c1bc053a64879a`）、
同一冻结语料（314 份文档，知识库 `c1036b98-0312-401d-8f7e-f6d4c627a04c`）、同一公平检索配置
（candidate_k=16、context_k=4、context_chars=10000，仅切换向量/BM25+RRF/重排）、
同一批原子事实与证据区间绑定。差异只有平台代码。

两次的有效题数不同（基线 48/50/50，v1.82 46/46/48），直接比总体指标会把题集差异混进来。
因此按 question 文本配对，**只在两次都存在的共同题上比较**：拒答率按共同题计算，
各指标取共同题均值。

## 对照：只加逐调用重试的那一轮

同一批题、同输入下，仅启用逐调用结构纠正重试时 dense 为拒答率 0.7708 → **0.7872**、
CR 0.2812 → **0.2695**，是变差的。本轮改为片段覆盖定向重问后同档变为 0.7174 / 0.3188。
两者差别只在"是否把缺失片段清单明确告诉模型"，因此可以确认起作用的是定向重问这一项。

## 需要注意的限制

- **恢复与变差题没有一道属于 8 道 AI 存疑题**，所以翻转不是标注模糊造成的噪声；但样本量小
  （三档各 3–4 道恢复、1–2 道变差），单档的翻转计数不足以支撑强结论，可信的是三档方向一致。
- **71.7% / 67.4% / 75.0% 的拒答率仍然很高**。本次修复只覆盖 check 协议失败这一片，
  约占拒答的三分之一；占约一半的 grade 判证据不足（子块级检索未把含答案片段送进上下文）
  完全未改动，仍是拒答主因。
- Context Precision 在 dense 与 full 上略降（−3.8 / −2.4 pt），hybrid 上略升（+3.3 pt）；
  hybrid 的 Faithfulness 由 1.0000 降至 0.9852。这些都在小样本波动范围内，未做显著性检验。
- 参考答案与证据区间为 AI 辅助生成、未经独立人工复核，本文件是系统行为的技术参考，
  不是人工金标基准成绩。
- 单次运行，未做重复采样；模型温度固定为 0，但不排除服务端波动。
