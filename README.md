面向个人知识库和小团队的 RAG 工程项目。基于已有复现工程进行验收与修复，提供 Vue 页面、双库持久化、异步入库、检索调试、带证据核验的问答、持久 SSE 与质量评测。原冻结版本和首次实验保留在本目录之外，本目录为独立生产候选版本。

**已完成真实双库及百炼联调、小样本质量验证与 24 小时长稳观测；公开基准已完成一次 AI 辅助标注子集的三档实测（技术参考），经独立人工复核的未见质量集尚未执行。** 不把 Mock/SQLite、缓存重放、固定缩减语料回归成绩当作生产吞吐、未见质量或完整官方基准成绩。

## 核心实现

- FastAPI + Tortoise ORM；MySQL 保存用户、文档、任务、对话、轨迹与评测，PostgreSQL 18 + pgvector 0.8.6 保存 1024 维向量。
- PDF/DOCX/XLSX/Markdown/TXT 解析，递归/短段/父子分块；保留原文位置和来源。
- Vector + jieba BM25，按排名 RRF 融合，保留百炼 Rerank 原始分数，回溯父块并约束上下文预算。
- 显式 LangGraph route/rewrite/retrieve/grade/generate/check/fallback；检索和生成独立重试上限。
- 文档版本与租约隔离：未发布索引不可检索，取消/过期/版本变化时禁止迟到正式答案。
- MySQL 持久运行队列与 SSE 序号事件，断线后后台执行，续订去重、重启回放与终态补偿。
- 支持限定否定回答；引用 ID、格式与逐字证据由后端校验，原文及位置映射保留，事实支持另行核验。
- 四项质量指标和带独立相关子块标签的辅助 P/R/F1；缺失和 Judge 冲突单列。

## 启动

需要可用 Docker Engine/Compose；Python 3.12+ 仅用于生成配置。初次从本目录执行：

```powershell
python -X utf8 scripts/setup_env.py --mode production
```

临时将生成的 `.env` 中 `ENABLE_REGISTRATION=true`，然后：

```powershell
docker compose -p zhixu-rag up --build -d --scale worker=2
```

打开 http://127.0.0.1:8080，创建账号后关闭注册并重新 up。默认 Demo 在真实双库上走通工程流程，不产生模型费用；接入已有百炼凭据后使用 qwen-plus、text-embedding-v4、gte-rerank-v2。密钥只保存在本地环境。

详细说明：[启动与运维](docs/启动与运维.md)、[生产验收计划](docs/production_acceptance_plan.md)。文档包含隔离端口、模型预算、演示顺序、排空停机与备份恢复。

## 验证与证据

依赖按 requirements.lock 和 frontend/package-lock.json 锁定；Docker 构建使用 Python 3.12，宿主机测试版本单独记录。pytest 覆盖权限、租约、索引发布、引用协议与 Agent 边界；前端 Node 测试覆盖 SSE 与恢复。真实双库测试需单独空数据库及显式隔离标志。

冻结 v3 的历史记录：仓库 160 项通过（13 真实双库、147 Mock/SQLite），另 1 项账本保护。固定回归集 151 单元协议终止 0；答案符合 106/146、误拒 31/148；仅 3 个有效不可答单元，不能推断整体无幻觉。官方标准与 AI 审阅、Judge 冲突和缺失均保留。该集合已用于错误分析和开发，不能称为未见验收。

本候选版的验证记录见 [docs/acceptance](docs/acceptance/)：生产验收报告、24 小时长稳结果（1,422 次采样、0 失败，**该结果属于 v1.81**）与 v1.81 测试结果（713 本地 + 21 真实双库、0 失败）。**v1.83 的 24 小时长稳未通过**（1 次失败采样、346 秒观测空档超过 180 秒阈值；同期并行跑着基准与测试，疑似争用，无法证实），详见 [soak_v183_failed.md](docs/acceptance/soak_v183_failed.md)——因此当前版本不能引用 24 小时长稳结论。v1.82 修复后重跑本地测试 727 项通过（21 项集成用例因未启动真实双库而跳过，不计入通过），`ruff check` 与格式检查在 `app scripts tests` 范围内通过；本轮未重跑真实双库、页面验收与 24 小时长稳，逐题复现证据见 [核验协议修复记录](docs/check_protocol_retry_v82.md)。公开基准（CRUD-RAG）已于 2026-10-05 完成一次真实模型三档实测，结果与诊断见下节；该批评测标注为 AI 辅助生成，未经独立人工复核，只能作为技术参考。示例文档为合成资料，适合演示，公开评测语料和私有数据库不随源码发布。


## 公开基准实测（技术参考，非人工金标）

2026-10-05 在 CRUD-RAG 公开数据子集（314 份语料、50 题 test 集）上跑了 dense / hybrid / full 三档对比，
真实百炼模型。完整结果与逐环节诊断见 [benchmark/results_crud_20261005.md](benchmark/results_crud_20261005.md)。

**注意**：该批参考答案与证据区间由 AI 辅助生成、未经独立人工复核，因此只作为系统行为的技术参考，
不作为人工金标基准成绩。辅助子块 P/R/F1 因缺少人工核验标注记为缺失。

### 修复前基线（2026-10-05）

| 指标 | dense | hybrid | full |
|---|---|---|---|
| Context Recall | 0.281 | 0.370 | 0.360 |
| Context Precision | 0.865 | 0.837 | 0.890 |
| Faithfulness | 1.000 | 1.000 | 1.000 |
| Answer Relevancy | 0.333 | 0.340 | 0.339 |
| Document Recall | 0.986 | 0.967 | 0.967 |
| 拒答率 | 0.771 | 0.760 | 0.800 |

核心发现：证据文档召回率约 97–99%，但拒答率约 78%。逐条回溯定位到两个环节各占一半——
grade 判证据不足与 check 核验未通过（其中 15/18 是核验模型返回结构无效，rag 模式无重试直接拒答）。
系统实际作答的题质量很高（CR 0.92–0.96、Faithfulness 1.0）。

**2026-10-07 更正**：本页早期版本把 grade 一侧描述为"文档命中了但子块级片段没进上下文"，
该说法**已被证伪**——证据子块在 95%（基线）到 100%（v1.82）的拒答题中都**已在上下文内**。
按轨迹的重新归因见 [docs/refusal_attribution_v83.md](docs/refusal_attribution_v83.md)。

### v1.82 修复后复测（2026-10-06/07）

三档各重跑一次，与基线**按题配对**比较（同人工确认文件、同冻结语料、同检索配置，仅代码不同；
两次有效题数不同，故只在共同题上比）。完整对照与限制说明见
[benchmark/results_crud_v82_comparison.md](benchmark/results_crud_v82_comparison.md)。

| 档位 | 共同题 | 拒答率(基线) | 拒答率(v1.82) | Δ | 恢复 | 变差 |
|---|---|---|---|---|---|---|
| dense | 46 | 0.7609 | **0.7174** | −4.35 pt | 4 | 2 |
| hybrid | 46 | 0.7391 | **0.6739** | −6.52 pt | 4 | 1 |
| full | 48 | 0.7917 | **0.7500** | −4.17 pt | 3 | 1 |

三档方向一致（拒答率 −4.2 ~ −6.5 个百分点），恢复与变差的题均不涉及 8 道 AI 存疑题。
作为对照：只加逐调用重试、不做定向重问时 dense 是**变差**的（0.7708 → 0.7872），
因此可确认起作用的是"把缺失片段清单明确告诉模型"这一项。

**边界**：拒答率仍高达 67%–75%。按轨迹重新归因（[docs/refusal_attribution_v83.md](docs/refusal_attribution_v83.md)）：
check 协议失败已从基线的 15/18 降到 check 拒答的 12%–33%；当前最大的可疑误判是
**"语义核验全部 supported 仍被拒答"**，占全部拒答的 19%–31%，正是
`scope_no_upgrade_relaxation` 针对的路径。该规则**已改为默认开启**（v1.84）：
三档配对实测拒答率 dense 0.7174→0.5652、hybrid 0.6889→0.6444、full 0.7333→0.6000，
共恢复 15 题、**拒答翻转零回归**（没有一题从作答变为拒答），Context Precision 持平或上升、
Document Recall 不变。**这不等于零质量回归**：full 档 Faithfulness 由 1.0000 降至 0.9583
（经逐题核对为分母效应），且模态转换的边界尚未单独验证。
它只放宽"答案比原文更保守"，**原文弱而答案说成断定/事实仍一律拒绝**。
约一半拒答来自 grade，但抽样显示**多数是正确判断**（如问题问 2021 年数据、语料只有 2023 年）。

**拒答率不等于错误率**：参考答案与证据区间为 AI 辅助生成、未经独立人工复核，
其中相当一部分假定为可答而实际不可答。在缺少独立人工金标前，只能给出"拒答发生在哪一步"
的结构归因，不能给出误拒率。单次运行、样本量小（每档 1–4 道翻转），未做显著性检验。
